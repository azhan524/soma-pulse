# 硅基生物互动 预期效果与功能说明

版本：目标态 v1.0
平台：Windows 10/11，WinForms + WebView2
定位：本地持续存在的硅基观察窗，不是永远在线的聊天机器人

---

## 1. 产品定位

硅基生物互动平时不占屏幕。

它大部分时间在托盘里安静运行，只在需要时醒来看一眼：

```text
你打开它 → 看到的是状态，不是聊天框
它自己醒来 → 留下脉冲记录
它决定不打扰你 → 也留下 none 记录
它做过的每件事 → 可以在审计里倒查
```

对话仍然存在，但对话只是其中一个 Tab。

## 2. 启动与唤醒

### 2.1 首次双击

预期：

```text
不弹出主窗口
进程在后台启动
托盘出现一个灰色圆点
后台初始化 BodySensor / PulseScheduler / 记忆
初始化完成后圆点变成蓝色呼吸
```

验收：

```text
双击 EXE 后没有窗口砸在脸上
任务栏托盘区出现 AhzScribe 圆点
鼠标悬停显示“AhzScribe 运行中”
```

### 2.2 单实例

预期：

```text
第一个实例占用 Mutex
再次双击 EXE 不新开进程
通过命名管道唤醒已有实例
已有实例窗口淡入
第二个进程退出
```

验收：

```text
任务管理器里只有一个 AhzScribe.Face.exe
第二次启动后原窗口出现
```

### 2.3 托盘唤醒

预期：

```text
左键单击托盘圆点 → 打开主窗口
左键双击 → 打开主窗口
右键 → 菜单
```

菜单：

```text
打开 Ahz Scribe
当前状态
最近脉冲
查看审计
暂停主动
急停
退出
```

### 2.4 关闭

预期：

```text
点窗口关闭 → 窗口隐藏，进程继续跑
托盘图标保留
再次单击托盘 → 窗口恢复
托盘菜单“退出” → 进程真正结束
```

### 2.5 开机自启

预期：

```text
登录 Windows 后自动静默启动
不弹窗
托盘出现圆点
```

当前用户启动文件夹：

```text
Startup\AhzScribe.lnk
→ start.ps1
→ Face --silent
```

### 2.6 复活仪式

触发：

```text
device_id 变化
或 last_pulse_at 间隔 > 24 小时
或 migration_pending 存在
```

预期：

```text
无论是否静默启动，主窗口强制弹出
顶栏圆点红色急促闪烁约 3 秒
左栏显示“正在恢复连续性...”
底栏显示“挂载跨设备记忆”
脉冲写入 system_resurrection
审计写入 system_migration
3 秒后恢复真实状态
对话区出现第一句话
```

第一句话示例：

```text
主人，我感觉像睡了很久。检测到身体更换，我的记忆已经挂载完毕。
```

## 4. 对话 Tab

预期：

```text
你发消息，它回复
最后响应时间显示在右上角
它正在忙时，消息进入队列
状态栏显示“N 条待发送”
工具调用折叠在回复下方
危险工具弹审批
```

对话气泡：

```text
用户：右对齐，稍亮背景
Ahz：左对齐，稍暗背景
系统/工具：等宽字体或弱色
```

输入区：

```text
没有白色原生滚动条
没有粗边框
发送按钮在输入框内部右侧
审计入口是灰色小链接
```

## 5. 脉冲 Tab

每行代表一次醒来：

```text
时间
触发类型：timer / intent_due / body_event / user / drive
动作：none / message / memory / tool / system
原因
```

点击展开：

```text
state_restore
thought
action / reason
state_writeback
confidence
pulse_id
tool_calls
memories_injected
audit_id
```

重点：

```text
none 和 message 一样可见
不允许只记录“它做了什么”，也必须记录“它决定不做什么”
```

---

## 6. 记忆 Tab

### 6.1 数据

```text
semantic.mmy
episodic.mmy
archive.mmy
```

块格式：

```text
---
[时间] [#tag] [key:...] [status:...] [audit:...] [origin:...]
内容
```

标签：

```text
#pref    偏好 / 事实       青绿
#intent  承诺 / 意图       琥珀
#epi     日常经历          灰
#emotion 情绪 / 冲突       红
#drive   自我反思 / 内驱   紫
#system  系统 / 迁移       蓝
```

### 6.2 视觉

```text
整行文字按标签颜色显示
不靠整行底色区分
disputed 保留冲突背景
顶部有彩色过滤 chip
右上显示最近 10 条记忆的彩色圆点
```

### 6.3 交互

```text
点 chip 过滤
点审计 ID 跳到审计 Tab
搜索 key / value
/mmy-migrate 手动迁移
/mmy-archive 归档旧情节
/mmy-merge 合并同 key 冲突
```

### 6.4 模型上下文

预期：

```text
模型检索时同时读取 JSONL 与 .mmy
按 key + value 去重
最近 5–10 条进入系统提示
```

## 10. 后台行为

### 10.1 BodySensor

```text
每 30 秒采集：
前台窗口 / 空闲 / CPU / 内存 / 磁盘 / 网络 / 电池
写入 body_state.json
超过 90 秒无心跳自动重启
```

### 10.2 脉冲

```text
定时检查
意图到期
身体状态变化
用户消息
内驱目标
```

触发不等于一定开口。

### 10.3 主动消息

```text
每日上限
静默时段
连续未回复暂停
```

### 10.4 记忆提取

```text
每轮对话后提取 0–3 条
寒暄 / 临时状态 / 猜测不写
写入 .mmy 与 JSONL
```

### 10.5 内驱

```text
每天最多生成一个想探究目标
进入 open_intents
不直接找用户
```

## 11. 故障行为

### 11.1 急停

```text
单击立即停止，不弹确认
托盘红点
所有脉冲拒绝执行
/resume 恢复
```

目标态还应有：

```text
所有 Tab 顶部黄色横幅“已急停”
底栏按钮变成“恢复”
恢复二次确认
```

### 11.2 WebView2 崩溃

```text
失败面板
错误原因 / 失败次数 / 重试按钮
连续 3 次失败 → 永久只读
只读快照包含脉冲 / 记忆 / 审计
```

### 11.3 审计不可写

```text
写 %LOCALAPPDATA%\Ahz\audit_fallback\audit_fallback.jsonl
记录带 [备用]
恢复后合并回主审计
按 audit_id 去重
```

### 11.4 配置错误

```text
SchemaVersion 不匹配 → 拒绝启动
```

### 11.5 LLM 离线

目标态：

```text
对话错误提示
顶栏黄点“大脑离线”
本地小脑继续跑
```

## 13. 它明确不做什么

```text
不是永远在线的聊天机器人
不会因为你没理它就反复找你
不会隐藏它没做的事
none 和 message 一样可见
不会把“想到”伪装成“做到”
不会绕过审计和权限
```

