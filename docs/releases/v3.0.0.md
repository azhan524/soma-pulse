## What this release is

SomaPulse is the project name for the verified functional silicon life
candidate. AhzScribe is the persistent Agent inside the project.

This release demonstrates:

- explicit identity invariants and mutable device/model separation;
- provenance-aware memory and auditable actions;
- evidence-driven adaptation with ablation;
- bounded health, resource and failure behavior;
- transactional model/device migration;
- autobiography and long-term attention;
- consolidation, soft forgetting and recovery;
- bounded goals with normal `none` and `wait` outcomes;
- isolated, approved self-evolution with automatic rollback.

It does not claim subjective consciousness, real feelings, awakened life or
unbounded autonomous action.
